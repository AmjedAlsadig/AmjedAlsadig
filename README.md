## Some things I've built

**[Autonomous Multi-Modal QA Agent](https://github.com/AmjedAlsadig/Multi-Modal-QA-Agent)**

An AI agent built to compete in a live trivia tournament — routes questions between a sandboxed Jupyter kernel for math, faster-whisper for audio, and RAG for live news lookup.

**[FLEX: EV Charging System](https://github.com/AmjedAlsadig/Flex-EV-Charging-System)**

Smart-grid optimization system. I worked on the async FastAPI backend and the MILP models that decide how charging gets allocated.

**[ML Data Annotation Platform](https://github.com/AmjedAlsadig/ML-Data-Annotation-Platform)**

A full-stack SaaS tool for computer vision data labeling.

**[Fixit: Home Services App](https://github.com/AmjedAlsadig/Home-Services-App)**

Cross-platform Flutter app for booking home services — I handled the maps/geolocation integration and widget testing.

**[Predictive Maintenance: SVM Fault Detection](https://github.com/AmjedAlsadig/Induction-Motor-Fault-Detection-SVM)**

Used SVMs to catch electrical faults in three-phase induction motors before they fail.
